# 布局 → 提示词：AI 译者

这份文档定的是"画布上的框"怎么变成**别的模型能照做的一段话**。画布本身（坐标、框、关系）
在 `lib/models/layout_spec.dart`；这里是它后面那层。

## 为什么不是模板

模板能保证坐标不丢，保证不了语义：它不知道"镜子里那个人和外面这个是不是同一个"，
也不知道光从哪来。2026-11-01 用同一份布局、同一工作流、同一个种子跑过三次
（`krea2 t2i workflow`，896×1344，8 步 turbo）：

| 变体 | 布局 | 镜面一致性 | 风格 |
| --- | --- | --- | --- |
| 模板散文（中文） | 对（镜像左上、窗右、床下、人在中） | **错**：镜中是另一个人，姿势也不同 | 动画、成立 |
| AI 译者（中文） | 对 | **对**：同一件白短袖、同一头黑发、同样的手部动作 | 动画、成立 |
| AI 译者（英文） | 对（镜子偏大） | **对** | **漂移成摄影风** |

三条结论：

1. **关系类的错，只有 AI 能修**。模板写"镜中映出正面朝向的她"，模型就画了另一个人；
   译者写"镜中映出的是同一个人，同样的黑长发与白短袖，姿势与本人一致、仅左右翻转，
   不要画成另一个人"，就对了。
2. **比例只到"量级正确"**。三版人物高度都在画幅的 45%~50%（框是 56%），误差 ±10%；
   精确比例只能靠 bbox / 色块图这类空间条件，文本做不到。
3. **风格锚点必须原样带过去**。英文版没有风格词，就直接漂成摄影；中文版沿用用户给的
   动漫语境才守住。**别自作主张翻译或补风格词。**

## 译者指令（自然语言系）

**真源只有一处**：`server-rs/src/ai/layout_translate.rs` 的 `INSTRUCTION`
（版本号 `TRANSLATOR_VERSION`，改指令必须 bump）。本文不再抄一份，只记**为什么这么改**。

### v1 → v2（2026-11-01）：加空间结构

`camera`（俯视/平视/仰视）与每个框的 `surface`（左墙/右墙/正墙/地面/桌面）。
只有 x/y 时模型只能把所有东西摊在一面墙前；有了"挂在哪个面"，"两面墙垂直、墙角在画面中部"才说得出来。

### v2 → v3（2026-11-01）：把"一致"拆成可核验的条目

用户拿了一版**人工手写**的提示词来对比，那版的约束力明显更强。差距不在文笔，在于：

| 手写版的做法 | v2 的问题 | v3 的改法 |
| --- | --- | --- |
| 镜像一致拆到"哪只手、握法、手指排列、梳子朝向、接触点、不对称发饰落在镜像侧" | 只写"同一个人、姿势一致、左右翻转" | 规则 9：逐项写到底，单侧元素必须翻到对应侧 |
| 写关系的同时写**排除**（"镜中不额外出现整理刘海的另一只手"） | 只有"不新增主体"这一句笼统的 | 规则 10：点名的否定——"不出现第三只手""不重复第二把梳子" |
| 视线落点（"倒影的目光落在真人眼睛上，不看向镜头"） | 没有 | 规则 11 |
| 接触写实（梳齿插进发丝、鞋底贴地、镜框压在桌沿上） | "相接触"三个字 | 规则 12：接触点 / 贴合面 / 谁压着谁 |
| 影子方向全场景一致 | 只要求"补光照投影" | 规则 13：写明落哪一侧，且所有物体一致 |
| 镜像不越出镜框、镜中是同一房间的连续环境 | 没有 | 规则 17 |
| 一段一个对象，段内"在哪 → 是什么 → 与谁怎样 → **不出现什么**" | 按面积整段连写 | 规则 7：固定段落结构 |
| 长度随对象数增长（那版 1200+ 字） | **封顶 120~200 字** | 规则 18：每框 60~120 字，总长不设上限 |

最后一条是根因级的问题：**封了长度就等于逼它删约束**。v3 的实测输出 1170 字、六个框，
每个框一段，各自带点名否定与影子方向。

### v3 → v4（2026-11-01）：正文改英文、一个框一段

英文是这些模型的母语，指令模型（尤其蒸馏过的）对英文结构词更敏感；分段则让"一个框一段"
成为可数的事实，校验器据此有了一个**与语言无关**的兜底指标（段落数 < 框数 = 有人被合并）。

代价：正文英文、标签中文时无法做字面覆盖检查，所以校验改成"ASCII 标签查字面 + 段落数兜底"。

一句话总纲仍然是：**宁可牺牲语言的流畅性，也不要牺牲空间关系的准确性。**

## 输出的形状

```jsonc
{
  "prompt": "…",
  "negative": "…",            // 可空；只在有明确要排除的东西时给
  "coverage": [{"id": "m", "how": "镜中映出的是同一个人…"}],
  "notes": ["比例用景别表达，未使用百分比"]
}
```

`coverage` 不是为了好看：它是校验器的输入。

## 五条确定性校验（不需要模型）

1. **覆盖**：每个框的名称或它在 `coverage` 里的说法必须出现在 `prompt` 里；
2. **不新增**：`prompt` 里不能出现规格之外的主体（用框的名称集合 + 常见名词表挡）；
3. **关系保留**：规格里有 mirror，正文必须出现"同一个人/镜像/一致/翻转"这类词；
4. **方位不矛盾**：按框算九宫方位，正文里该框附近不许出现相反的方位词；
5. **比例**：要么用景别表达，要么数字与规格一致——不许自己编一个。

1/3/4 能抓住绝大多数"AI 自由发挥"。不过就重试一次，再不过退回模板——
**模板是质量下限，不是产品**。

## 落地位置

**已实现**：`POST /api/layout/translate`
（`server-rs/src/ai/layout_translate.rs` + `lib/pages/layout_canvas_page.dart` 的「让 AI 写」按钮）。

- 入参 `{ spec, intent, providerId, model }`，出参 `{ prompt, ok, issues, attempts, model, translator }`；
- 用**工作台当前选中的** Provider / 模型，不另开一套配置；
- 不过就带着 issues 重写一次；再不过 `ok=false`，前端保留模板；
- **接口不返回模板**：模板是 `lib/models/layout_spec.dart` 里的纯函数，手机端也要用，
  不能在后端再写一份；
- 五条校验里已落四条（覆盖 / 格式 / 关系 / 方位-保守版）。「不新增主体」需要名词抽取，
  纯文本规则判不准，**宁可不报也不误报**，留到有模型侧抽取能力时再加。

指令版本 `layout-translator/2`：**改指令必须 bump**，它是回归对比的锚点。

## 空间结构：从平面到墙角（2026-11-01）

只有 x/y 的时候，模型只能把所有东西摊在**一面墙**前。用户的原话：
"我要的不是这种平面场景，比如镜面在一堵墙上，而床和窗户在紧挨着的另一堵墙。"

规格里因此多了两个字段：

- `camera`：`auto` / `topdown` / `eye` / `low`。机位决定**透视**，不是构图 ——
  俯视才看得见桌面，平视才看得出两面墙的竖向关系；
- 每个框的 `surface`：`left` / `right` / `back` / `floor` / `table`。
  有了它，"两面墙垂直"这种关系才说得出来。

实测（832×1248、eye、镜+桌在左墙、窗+床在右墙）：

> 视线平齐的机位，正对房间墙角：左墙与右墙在画面中部交汇成一条竖直角线。
> 左侧墙面上方挂着一面镜子……右侧墙面的上半部开着一扇窗，窗户下方的同一面墙前
> 放着一张床，床头靠着墙角一侧。女生站在地板上……镜中映出她的上半身：脸朝向镜子，
> 同样的发型与衣领，仅左右翻转。

## 深度图：试过，删了（2026-11-01）

曾经加过 `POST /api/layout/depth`，从布局直接渲一张灰度深度图喂 ControlNet。**已经整段删除**，
原因值得记下来：

- 框只有矩形，渲出来就是**方块**。真实的深度图里人是圆的、床有褶皱——那些轮廓信息
  **不在布局里**，凭空造不出来（用户原话："深度图还包括物体实际轮廓，我们如何凭空得到？"）。
- 试过两版：①每框一个灰度、按远到近贴 → "黑底上几张贴纸"；②针孔相机 + 房间四壁 + 体块
  光线求交 → 有透视和体积了，但物体仍是柱体，ControlNet depth 读不出形体。
- 结论：**轮廓要么来自生成结果（DepthAnything 反推），要么来自素材（抠图），要么就不要。**
  前者是"事后锁构图"，不是"事前蓝图"。

要做这类事，正确的形态是**两段式**：先出图 → 对图跑深度 → 低 denoise 再跑一轮锁构图。
那属于工作流编排，不该塞进布局工具。

## 镜面一致性的天花板

**文本指令只能提高命中率，保证不了。** 两次实测：镜中人的衣着对上了，但手上的动作
（举梳子 vs 双手拢发）仍然各画各的 —— 那是"同一性"约束，属于模型先验的盲区。

真解法是**几何或局部重绘**：镜框当 mask 做 inpaint（保证重画），或从正面参考图合成。
注意"把背影水平翻转"在"镜子在人物正前方"的构图里**是错的**——镜中是正面，翻转背面得不到正面。
