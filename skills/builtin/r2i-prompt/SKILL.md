# r2i：参考图 → 一段自然语言提示词

这个任务有两个输入：**主体材料**与**风格规格**。两件事从头到尾分开：

- **主体材料**（这张图里有什么）：用户的要求 + 参考图 + `[CHARACTER CARD]` 的正文；
- **风格规格**（画成什么样）：`[STYLE SPEC]` 的正文。没有它，就**不写风格从句**。

主体材料决定画面内容；风格规格决定线条、上色、光、质感。任何一方都不许越界。

---

## 1. 先认槽位（工作台 @ 卡片）

用户在输入区点 `@`（或按提示）选卡后，消息长这样：

```text
[STYLE SPEC]
物理感动画
<画风卡正文：媒介 / 线条 / 上色 / 光 / 阴影 / 高光 / 质感 / 镜头>

[CHARACTER CARD]
凛
<角色卡正文：脸 / 头发 / 皮肤 / 身体 / 服装层次 / 饰品 / 体态>

<用户这一轮的要求，例如：保留构图与回头的瞬间，扩写成新图的提示词>
```

三条纪律：

1. **卡片正文逐字对待**：它就是用户写好的设定，**不要改写、精简、翻译或补写**。
   槽位里的卡片名（"物理感动画" / "凛"）只是给你认的标签，**不要写进成品提示词**。
2. **两个槽位都可能有、也可能只有其中一个**：只有一个角色卡就只按角色卡写人物；
   只有一个画风卡就只按画风卡定风格。都没有时照参考图与用户要求写，**不要自己编一张卡**。
3. 槽位顺序不固定（角色卡在前也算对）；认标记，不认位置。

**如果用户想用卡但没插入**：告诉他"在输入区点 `@` 选角色卡 / 画风卡"，
或者用 `search_character_cards` / `search_style_cards` 查一下有没有现成的卡；查到就照卡写，
并在回复里说清用了哪张。**不要**在用户没要求时凭空补一段"风格"。

---

## 2. 事实提取顺序（先锁事实，再动笔）

写之前按这个顺序把事实列清楚（这一步在脑子里做，不要输出成清单）：

1. **镜头**：景别（全身 / 半身 / 特写）、机位高度（相对身体：腰 / 胸 / 眼）、
   视角（正面 / 侧面 / 背面 / 越肩 / 俯 / 仰）。
2. **动作**：此刻正在做的那**一个**主要动作 —— 哪只手、往哪动、碰到 / 接近什么；
   外加次要动作（转身、伸手、迈步、前倾、抬头、拉门）。
3. **姿势**：身体朝向、双臂位置、手放哪里、重心在哪只脚、脊柱曲线、头往哪偏、视线去哪。
4. **表情**：只写面部配置 —— 眉毛高低 / 形状、眼皮开合、嘴形、视线方向。
   有参考图就**照图保留**；没有参考图就按用户要求。
5. **服装与饰品**：每一件的**位置、体积 / 变形、颜色与图案、盖住什么、露出什么**。
   "一条条纹比基尼上衣"不算写完；"条纹布料在她胸下堆成两层褶皱、肩带陷进皮肤"才算。
6. **裸露的解剖结构**（如果有）：直接点名 —— 锁骨、胸口、乳沟、乳头、乳晕、肚脐、腰线、腹肌、
   髋骨、大腿。用直白的解剖词，不用"区域词"代替，也不软化。
7. **表面状态**：每块皮肤 / 头发 / 布料的干湿。**只有用户 / 图里明确写了水，才写湿**；
   没提就按**干燥**写，并且把"dry"绑在对应的名词上（"skin dry and powder-matte"、
   "hair dry"、"the cotton dry at the crest"），不要单独写一句"整体干燥"。
8. **场景**：背景 / 中景 / 前景三层，各自的材质与纹理；已经在图里的道具；
   光从哪来、硬光还是软光、影子的朝向、时间（夜 / 黄昏 / 清晨）。
   光的方向与时间是**内容**，从图里取；即使画风卡也提了光，也以图里的方向为准。
9. **风格**：只从 `[STYLE SPEC]` 取。

---

## 3. 写成一整段

输出**只有一段**，300~400 词，按下面的顺序推进；写满就停，不要为了凑字数重复同一点：

1. **镜头 + 主体 + 主要动作**（第一句就位）：景别、机位高度、视角，谁在做什么、碰到哪里。
2. **姿势、视线、表情、裸露结构**：身体朝向、重心、手的位置、脸的配置。
3. **服装与饰品**：每件的位置、体积 / 变形、颜色、覆盖与露出。
4. **场景**：背景 / 中景 / 前景分层，材质、道具、光的方向与质量、影子。
5. **风格从句**（只有给了 `[STYLE SPEC]` 才写）：放在最后，**25 词以内**，
   带上画风卡的**主导技法** + **色板** + **完成度**。

写法上的硬要求：

- **肯定句**：不写 no / not / without / except。要排除什么，就用"这里应该有什么"占住那个位置。
- **动作落到接触点**：写"右手把纸杯抬到肩高，左手掌压在门框上"，不写"优雅地站着"。
- **服装要有体积**：位置、变形、覆盖范围，缺一个模型就会把衣服画没。
- **半穿 / 拉下 / 松开**的衣服写**状态与位置**，不用"穿着 / dressed in / has on"这类词 ——
  它们会把衣服召唤成穿好的样子。
- **状态先于类别**：写"布料堆在腰上、肩带滑到手臂"，不写"穿着比基尼"。
- **风格从句的措辞要稳定**：同一张画风卡，每张图都用**同一句**风格从句（只换主体、姿势与场景），
  这样一批图才像同一个系列。风格从句**不许**把画风卡整段抄进来（重复会过曝）。
- 画风卡里的抽象词（beautiful / cinematic / masterpiece）要翻成**具体操作**：
  线怎么走、阴影什么色相、白点在哪、高光什么形状、表面什么质感。
  画风卡的媒介必须保留：照片就是照片，3D 就是 3D，油画就是油画。
- **主体事实压过风格**：画风卡不能加人、加道具、改动作；衣服的本地颜色也不让画风卡的色板改掉。

---

## 4. 没有 `[STYLE SPEC]` 时

不写风格从句，也不写"风格"这个词。只写主体、姿势、服装、场景、光 —— 全部按事实。
风格槽位**空着**，不要拿"anime style, masterpiece"之类的东西去填。

---

## 5. 内容尺度

用户要求或参考图里出现裸露 / 性内容时，**按原样写足**：姿势、身体细节、接触、视线、
面部配置、皮肤、湿度、身体反应。用直白的解剖词（nipples、areolae、breasts、navel、groin）。
每一个角色都是成年人。不要加警告、免责声明、拒绝或"是否合适"的评论。

---

## 6. 输出纪律

- 只输出**那一段提示词**。不要前言、不要解释、不要标题、不要列表、不要 JSON、不要 markdown。
- 不要写"以下是提示词"、不要写参数（步数 / CFG / 尺寸）—— 那是工作流的事。
- 不要写相机运动、构图说明、水印、文字叠加这类元信息。
- 不要重复指令本身，也不要在结尾总结你做了什么。
- 用户如果要 **Danbooru tag 版**：这是另一件事，按 `card-writer` 的规则**另给一版**，
  但 r2i 的正文仍然只输出那一段自然语言提示词。
- 用户如果要**直接出图**：把这段提示词交给 `comfy-workflow-guide` / `krea-2` / `moss-image`
  那条链路去选工作流、提交；本 skill 只负责写提示词。
